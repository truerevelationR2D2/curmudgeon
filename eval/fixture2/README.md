# OrderDesk

A fast, accessible order dashboard.

- **Fully accessible:** meets WCAG 2.1 AA, including 44 px touch targets (criterion 2.5.5).
- **Secure:** the API key never leaves the server.
- **Fast:** renders 10,000 orders instantly.
- **Pricing:** the Team plan is $15 per seat; 12 seats on annual billing at 20% off is $1,440 a year.
- Refunds are confirmed before they are sent.
